# Xotix Fence Installation Rochester

Modern Next.js website for **Xotix Fence Installation Rochester**, a professional fencing company serving Rochester and Monroe County, NY.

## Features
- **Next.js 14 App Router** with TypeScript and Tailwind CSS.
- **Design**: Modern industrial dark theme (`#0d0f12`) with electric orange accents (`#ff5500`).
- **Comprehensive Structure**:
  - Homepage with interactive workflow, material spec cards, and Monroe County communities directory.
  - 11 Service Pages (Wood, Vinyl, Chain Link, Aluminum, Privacy, Fence Repair, Fence Replacement, Pool Fence, Gates, Commercial).
  - 13 Monroe County Location Pages with town-specific lot conditions, municipal codes, and local FAQs.
  - 10 Technical Blog Guides with pure white high-contrast body typography.
  - Contact Page with official address, direct phone link, and visible dark-mode Google Maps iframe.
- **Strict Content Boundary**: 100% of website content is sourced directly from the official specification sheet.
- **CTA Architecture**: Direct phone calling (`(585) 481-8674` / `tel:+15854818674`) with zero contact forms.
- **Performance**: High-resolution WebP images, static generation (SSG) across all 40 pages, and optimized responsive layouts.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
